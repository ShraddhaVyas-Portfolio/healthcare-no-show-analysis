Healthcare Appointment No-Shows Analysis
Project Overview
This project investigates factors associated with missed healthcare appointments.

The goal is to prepare a healthcare appointment dataset for machine learning modelling through data cleaning, exploratory data analysis, and feature engineering.

Business Problem
Missed appointments create operational inefficiencies for healthcare providers, increase waiting times, and waste resources.

This project aims to identify factors associated with patient no-shows and prepare a dataset suitable for predictive modelling.

Objectives
Collect and validate appointment data
Clean and prepare the dataset
Perform exploratory data analysis (EDA)
Create new features for machine learning
Document findings using visualisations
Build an ML-ready dataset
Project Scope
Research Question
What factors influence whether a patient attends or misses a healthcare appointment?

Planned Workflow
Collect data
Load and inspect data
Clean the dataset
Perform exploratory analysis
Create new features
Prepare data for machine learning
Communicate findings
